# 打断类弹窗

权限申请、评分引导、来电、桌面图标/通知类提示。共同特征：盖在业务页面上，脚本读不到正文。

## 分类与动作

| 类型 | 判据 | 动作 |
|---|---|---|
| 权限 | 「允许/拒绝」+「权限/访问/通知」 | 一律点**拒绝/不允许**（脚本不需要额外权限） |
| 评分 | 「评价/评分」+「不再提示」 | `dismiss_rating_popup()`，绝不点「去评价」 |
| 来电 | 「接听/挂断/来电」 | 点「挂断/拒绝」，绝不接听 |
| 桌面图标/通知 | `dismiss_blocking_prompts` 能识别 | 让它统一处理 |

## 红线

- 不点「允许/始终允许」：权限授予会改变后续脚本的假设（例如通知、存储弹窗不再出现）。
- 不接听来电：通话会占用音频和前台。
- 不点「去评价 / 好评」：会跳出应用去应用商店。

## 判据

处理完再 dump 一次，确认没有残留的「允许/拒绝」或「接听/挂断」节点。
