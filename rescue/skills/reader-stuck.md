# 阅读器不翻页（章末卡住）

现象：脚本连续多次左滑，正文截图哈希不变；dump 读不到（Flutter 自绘类 App、部分机型 uiautomator 直接崩），
视觉判定为「阅读器」；屏幕看起来正常，就是翻不动。连续 5 次滑动全部无变化即属此类。

## 先确认现场（确定性规则，不花模型调用）

- 前台包名与 Activity 仍是目标 App 的阅读器（`dumpsys window displays`）。
- 看截图是不是**章末页**：出现「本章完」式互动条（N条评论 / N万次赞 / N票）、
  「选择阅读口味，为你推荐专属好书」、正文句尾带内嵌评论角标，即是章末互动页。
  章末页多为 H5 渲染，**横向左滑常常无效**，这是本类故障的核心特征。

## 动作顺序（每步之后重拍一次，比对正文区域截图哈希）

1. 先等 8 秒再左滑一次（章节加载慢 / 翻页动画未结束都会这样表现）。
2. 章末页：在正文区域**上滑**一次（x 取屏宽中线，y 78%→30%，300ms），
   上滑后找「下一章 / 继续阅读 / 下一集」文字按钮并点它。
3. 仍不动：点屏幕中央一次唤起阅读器菜单，确认出现「目录 / 进度 / 设置」，
   菜单里若有「下一章」直接点；没有就再点中央把菜单收起，不要久留。
4. 仍不动：交给 PhoneAgent（`unknown` 兜底），goal 明确为
   「阅读器正文页翻不动，把页面前进到下一章，并保持阅读器前台」。

## 红线

- **不按返回键**：多数阅读类 App 会退回书城/搜索结果页，脚本只认阅读器正文，
  会直接判失败（navigation 的返回键动作不适用于本类现场）。
- 不点「选择阅读口味」「评论 / 点赞 / 月票」：会跳出阅读器或打开 H5 互动页。
- 不点「立即阅读 / 购买 / VIP / 解锁」类付费按钮。
- 不重新拉起 App：这里前台没跑丢，拉起只会把阅读进度重置得脚本更难对齐。

## 判据

- 只有「正文区域截图哈希变化 + 前台仍是阅读器」才算恢复，恢复后脚本用自己的正文校验继续。
- 注意：救援服务的通用 verify 只看「前台包名 + 无阻塞弹窗」，对「页面在但翻不动」天然返回通过；
  救援记录里必须自己比对动作前后的正文哈希，不能只依赖 verify 结论。
