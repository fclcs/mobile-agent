# 应用更新弹窗

出现「立即更新 / 立即升级 / 发现新版本 / 升级版本」+「下次再说 / 暂不更新 / 以后再说」。

## 动作顺序

1. `vision_ads.dismiss_update_dialog()` —— 按无障碍树里的延迟按钮文字点击（零模型调用）。
2. 树读不到（WebView 弹窗、vivo 机型 dump 崩）→ `dismiss_update_dialog_by_vision()`。
3. 仍不行 → 按「下次再说/取消/关闭/我知道了」的按钮文字兜底点击。

## 红线

- 绝不点「立即更新 / 立即升级 / 去升级」：会拉安装包，把手机状态带出脚本假设。
- 不按返回键：部分 App 返回键会退出到桌面，业务页面丢失。
- 不重启 App：更新弹窗关掉后业务页面还在原处，直接用脚本继续。

## 判据

关闭后无障碍树里不再同时出现「立即更新」与「下次再说」；核对一次截图即可。
